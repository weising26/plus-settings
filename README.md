# Plus+ Settings page

A single web page that connects over Web Bluetooth to an nRF52 Plus+ emulator
running firmware with the settings service, and changes its settings:
auto-catch, auto-spin, Pokemon Sleep data, light sleep delay, pairing reset,
plus a status readout.

Open the GitHub Pages address of this repository in **Chrome on Android**,
disconnect the device from Pokemon GO, then tap **Connect**.

This repository contains only the page. It holds no device keys, flash images
or BLE addresses.
